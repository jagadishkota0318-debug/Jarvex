# Jarvex

Jarvex is a digital enterprise — a modern, mobile-first web platform.

## Pages

- **Home** (`index.html`) — Landing page with hero section, services overview, and waitlist
- **About** (`about.html`) — Company information, stats, values, and testimonials
- **Services** (`services.html`) — Detailed service offerings
- **Process** (`process.html`) — How Jarvex works
- **Pricing** (`pricing.html`) — Plans and pricing
- **Contact** (`contact.html`) — Contact form and details

## Features

- Fully responsive design (desktop, tablet, and mobile)
- Custom cursor effects
- AI-powered chatbot assistant
- Scroll-based animations
- Mobile-optimized navigation

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Bebas Neue, DM Sans, DM Mono)
